# Computer Vision RE604

Repository for mata kuliah Computer Vision RE604.

## Struktur
- `Main.py`: kode utama untuk proyek.
- `CV-Midterm-Project.pdf`: dokumen proyek tengah semester.
- `emnist-*`: file dataset EMNIST (tidak disertakan di repo jika memungkinkan karena ukuran besar).
- `myenv/`: lingkungan Python virtual (diabaikan oleh `.gitignore`).

## Cara menggunakan
1. Aktifkan lingkungan virtual Python:
   - Windows PowerShell: `myenv\Scripts\Activate.ps1`
   - Windows CMD: `myenv\Scripts\activate.bat`
2. Pasang dependensi yang diperlukan.
3. Jalankan `Main.py` untuk mulai menggunakan proyek.

## Catatan
- Data EMNIST berada di folder ini tetapi lebih baik tidak menyimpan file dataset besar langsung di GitHub.
- Jika Anda ingin menambahkan file dataset, gunakan Git LFS atau unggah dataset terpisah.
